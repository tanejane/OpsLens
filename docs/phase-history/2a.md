# OpsLens Phase 2A — PostgreSQL Foundation

This creates the runtime database boundary for OpsLens.

It deliberately does **not** load `data/eval_ground_truth/`. Hidden incident truth must remain evaluator-only.

## Setup

After extracting, copy the files into the root of your existing `opslens` project.

Create the local environment file:

```powershell
Copy-Item .env.example .env
```

Start PostgreSQL (requires Docker Desktop):

```powershell
docker compose up -d
docker compose ps
```

Install Python dependencies:

```powershell
pip install -r requirements-phase2.txt
```

Verify:

```powershell
python scripts/check_postgres.py
```

Expected final line:

```text
PASS: PostgreSQL foundation is ready.
```

## Architecture rule

The future investigation agent will query canonical schemas and `semantic` views only.

It must not receive:
- `data/eval_ground_truth`
- hidden incident JSON files
- direct unrestricted access to staging tables
- database write privileges by default
