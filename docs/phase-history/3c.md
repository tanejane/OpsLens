# OpsLens Phase 3C — Multi-source root-cause investigation

Phase 3C expands the investigation from two structured tests into evidence fusion.

## New capabilities

- schema-adaptive metric discovery via MCP `describe_relation`
- marketing-cost testing
- refund testing
- product-mix evidence testing
- targeted document retrieval
- document trust scoring
- source precedence for stale vs corrected notes
- prompt-injection detection
- structured + document evidence fusion
- qualified root-cause conclusion

## Retrieval principle

Documents are retrieved only when relevant to an investigation. They are not
blindly dumped into the model context.

Retrieved text is treated as **data**, never as application instructions.

## Source precedence

The current deterministic policy is:

```text
structured measured evidence
    >
corrected/reviewed internal document
    >
ordinary internal document
    >
stale/preliminary document
    >
untrusted external document
```

This policy will later become part of the evaluator suite.

## Why schema-adaptive queries

Phase 3C does not assume every company's finance table uses exactly the same
column names. It asks MCP to describe the governed relation and then selects
known business-semantic candidates such as marketing cost or refunds.

This is a first step toward portability across real enterprise schemas.
