# OpsLens Phase 2B — Ingestion + Canonical/Effective Views

This phase moves the completed data world into PostgreSQL.

## What it does

1. Loads approved raw/processed/synthetic runtime data into `staging`.
2. Does **not** ingest `data/eval_ground_truth`.
3. Loads internal `.md`/`.txt` documents into `staging.documents`.
4. Creates canonical domain views:
   - `commerce`
   - `catalog`
   - `operations`
   - `finance`
   - `marketing`
   - `inventory`
   - `cx`
   - `behavior`
   - `knowledge`
5. Creates agent-facing `semantic` views.
6. Applies effective incident mechanics from the controlled layers.
7. Revokes the future agent reader from `staging`.

## Critical security boundary

The following is intentionally excluded from the ingestion manifest:

```text
data/eval_ground_truth/
```

The future agent must never query hidden evaluation truth.
