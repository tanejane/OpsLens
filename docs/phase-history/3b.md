# OpsLens Phase 3B — LangGraph + MCP + Evidence Ledger

Phase 3B replaces the Phase 3A execution stub with the real OpsLens MCP boundary.

## What it proves

```text
Question
  ↓
PlannerProvider
  ↓
planned evidence tests
  ↓
OpsLens MCP
  ↓
safe semantic SQL
  ↓
normalized evidence ledger
  ↓
hypothesis lifecycle update
  ↓
qualified conclusion
```

The current planner is `DeterministicBaselinePlanner`. This is intentional: it gives us a stable baseline before introducing LLM variability.

A future model provider can implement the same `PlannerProvider` interface, but the model will not own:
- permissions,
- SQL execution,
- budgets,
- stopping rules,
- hidden evaluation truth.

## Important limitation

This is not yet the complete INC_001 root-cause investigator.

It validates real MCP-backed evidence flow using:
- the profitability outcome pattern;
- COGS growth versus revenue growth.

Phase 3C will add marketing, documents/retrieval, source precedence, conflicting evidence, and broader hypothesis testing.
