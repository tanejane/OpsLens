# OpsLens Phase 3D — Hybrid Retrieval Engineering

Phase 3D upgrades document lookup into a measurable retrieval subsystem.

## Architecture

```text
knowledge.documents
      |
      v
chunking + metadata/date extraction
      |
      +--------------------+
      |                    |
      v                    v
Postgres FTS          FastEmbed BGE
lexical index         384-d embeddings
      |                    |
      +---------+----------+
                |
                v
        candidate retrieval
                |
                v
      Reciprocal Rank Fusion
                |
                v
 provenance/security reranking
                |
                v
         top evidence chunks
```

## Components

- paragraph-aware chunking with overlap
- `knowledge.document_chunks`
- PostgreSQL `tsvector` + GIN index
- pgvector HNSW cosine index
- FastEmbed `BAAI/bge-small-en-v1.5`
- dense semantic retrieval
- PostgreSQL full-text lexical retrieval
- Reciprocal Rank Fusion (RRF)
- trust/source-date reranking
- optional trust and temporal filters
- prompt-injection filtering
- Recall@3 and MRR evaluation

## Why hybrid

Dense retrieval is good at semantic similarity.
Lexical retrieval is good at exact names, incident IDs and business terminology.

OpsLens uses both instead of betting the investigation on one retrieval method.

## Build index

The first run downloads the small local embedding model.

```powershell
pip install -r requirements-phase3d.txt
python scripts/build_phase3d_index.py
```

## Evaluate

```powershell
python scripts/validate_phase3d.py
```

Target:

```text
Recall@3 >= 0.75
MRR >= 0.60
Prompt-injection chunks filtered from normal context
VERDICT: PASS
```

## MCP integration

`retrieval/mcp_extension.py` defines `search_knowledge()` as a typed MCP tool.

We do not yet overwrite the existing MCP server automatically. After retrieval
quality passes, Phase 3D.1 can register the tool cleanly in the server and add
its protocol-level test.

## Important interpretation

Retrieval metrics measure whether OpsLens finds the correct evidence.

They do not measure whether a hypothesis is true or what percentage of profit
decline a cause explains. Those are separate evaluation/attribution problems.
